# Распознавание речи на NeMo

Сервис принимает WAV и возвращает текст. Ровно тот же контракт, что у
контейнера `stt` на OVOS, поэтому переключение между ними — одна переменная.

```
POST /stt?lang=kk     тело: WAV, ответ: строка
GET  /health          жив ли, загружена ли модель
```

Модель — `nvidia/stt_kk_ru_fastconformer_hybrid_large`, двуязычная: казахский и
русский, язык выбирается сам для каждой фразы. Параметр `lang` принимается и
игнорируется — он остался в сигнатуре потому, что его шлют все вызывающие.

## Почему не Whisper

Восемь записей с производства, один и тот же звук через обе модели:

| | Whisper large-v3 | NeMo FastConformer |
|---|---|---|
| Номер партии распознан | 2 из 8 | **7 из 8** |
| 23.3 с звука обработано за | 256 с (2 ядра) | **0.7 с (4 потока)** |
| Придумывает на тишине | да | нет |

Первая строка — причина менять. Вторая — приятное следствие устройства:
FastConformer размечает звук за один проход, а не порождает текст токен за
токеном, поэтому обгоняет реальное время **без видеокарты**.

Третья строка важнее, чем кажется. Whisper на тишине писал «Редактор субтитров
А.Олзоева» — грамматически исправную фразу, которую разбор команд честно
пытался исполнить. У вас команда запускается по обратному отсчёту, без нажатия,
поэтому правдоподобная выдумка опаснее отказа. RNN-T на неразборчивом звуке
возвращает пустоту.

Смешанная речь, ради которой всё и затевалось, узнаётся как есть:
«үш жүз қырық бір **на расстойку**» — казахское числительное и русское название
этапа в одной фразе.

## Переключение и откат

В `.env`:

```bash
PM_STT_URL=http://stt-nemo:8080     # NeMo
PM_STT_URL=http://stt:8080          # обратно на OVOS + Whisper
```

```bash
docker compose up -d process-mining
```

Код аналитики при этом не меняется вовсе — адрес и так лежал в переменной.

## Запуск

```bash
docker compose up -d --build stt-nemo
```

Первый старт скачивает около 600 МБ весов в том `nemo_models`; поэтому у
healthcheck пятиминутная фора. Дальше модель поднимается из кеша за считаные
секунды.

Проверить, не выходя из хоста:

```bash
curl -s http://127.0.0.1:8081/health
curl -s -X POST --data-binary @запись.wav \
     -H "Content-Type: audio/wav" "http://127.0.0.1:8081/stt?lang=kk"
```

## Настройки

| Переменная | По умолчанию | Смысл |
|---|---|---|
| `NEMO_MODEL` | `nvidia/stt_kk_ru_fastconformer_hybrid_large` | какие веса брать |
| `NEMO_THREADS` | `4` | потоков процессора |
| `NEMO_MAX_UPLOAD_MB` | `32` | предел размера записи |
| `NEMO_PRELOAD` | `true` | грузить модель на старте, а не при первом запросе |

`NEMO_PRELOAD=false` полезен в тестах: сервис поднимается мгновенно, а веса
подтягиваются, когда действительно понадобятся.

## Тесты

```bash
pytest test_app.py -q
```

Девять штук, модель в них подменена: проверяется форма ответа, а не качество
распознавания. Качество меряется на записях из цеха — в юнит-тестах ему взяться
неоткуда.

## Что дальше

**Дообучение.** NeMo даёт его штатно, а видеокарта у вас уже есть. Материал
копится сам: каждая подтверждённая на доске команда — это пара «аудио → верный
текст». Не хватает только сохранения этой пары.

**Шум цеха.** Единственная цифра, которой до сих пор нет ни у одной модели.
Двадцать команд у работающей печи тем микрофоном, который будет у людей, — и
станет известно, нужно ли дообучение вообще.

**Другой язык у другого заказчика.** Эта модель знает казахский и русский.
Придёт заказчик с другим языком — меняется `NEMO_MODEL` или адрес в
`PM_STT_URL`. Сменность важнее того, какая модель стоит сегодня.
